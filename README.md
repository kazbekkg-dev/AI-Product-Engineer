# AI Product Engineer

Мой путь от начинающего разработчика до AI Product Engineer.

## Цель

Научиться проектировать, создавать, тестировать и запускать цифровые продукты с помощью программирования и AI-инструментов.

## Программа

- Sprint 0  Рабочая среда и Git
- Sprint 1  Основы веб-разработки
- Sprint 2  Первый коммерческий проект
- Sprint 3  Backend и API
- Sprint 4  Базы данных и авторизация
- Sprint 5  AI-интеграции
- Sprint 6  Мобильная разработка
- Sprint 7  SaaS и автоматизация
- Sprint 8  Портфолио и фриланс
